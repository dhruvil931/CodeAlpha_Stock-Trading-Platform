# 📈 Stock Trading Platform

A Java-based Stock Trading Platform that simulates basic stock market operations such as buying and selling stocks, portfolio management, and transaction tracking.

## 🚀 Features

- View available stocks and prices
- Buy stocks
- Sell stocks
- Portfolio management
- Transaction history tracking
- Balance validation
- Profit/Loss calculation
- Object-Oriented Design implementation

## 🛠️ Tech Stack

- Java
- OOP Concepts
- Collections Framework
- MySQL

## ⚙️ Functionalities

### Buy Stock
- Checks user balance
- Updates portfolio
- Stores transaction history

### Sell Stock
- Validates stock ownership
- Updates holdings
- Adds balance after selling

### Portfolio Tracking
- Displays owned stocks
- Calculates current portfolio value

## ▶️ How to Run

1. Clone the repository
2. Open project in IntelliJ / VS Code
3. Compile and run `Main.java`
